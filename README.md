# スマホの中の3日間

中学生向けの「生成AI・情報モラル」体験型シミュレーション教材です。
スマホの画面の中で3日間を過ごしながら、実際に起こりうるトラブルを安全に体験して学びます。

| 日 | テーマ | 内容 |
|---|---|---|
| 1日目 | ハルシネーション | AIの答えで宿題を出すと再提出 → 公式サイト・図書館で確かめ直す |
| 2日目 | 個人情報とSNS | AIに個人情報を教えた／写真や初期設定から住んでいる場所が特定される → 設定を見直して再投稿 |
| 3日目 | ネット詐欺・乗っ取り | にせSMS（ウイルス）、PHPの脆弱性による情報流出とパスワード使い回しによる乗っ取り・2段階認証、にせのウイルス警告 |
| まとめ | まとめ問題10問 | 結果・修了証 |

- 所要時間：約20〜25分（タイトル画面の「日にちを選んで始める（先生用）」で日ごとに分けて使えます）
- Chromebook のブラウザで動作します。`index.html` 1ファイルだけで動き、通信は行いません
- 登場するアプリ・人物・会社・サイトはすべて架空です
- 2日目の写真は Canva の画像生成で作成しました
